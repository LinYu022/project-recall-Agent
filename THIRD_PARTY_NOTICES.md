# Third-party boundaries

The MIT license applies to the project's original code and documentation. It does
not relicense dependencies, official records, PDFs, model weights or API services.

- Python and frontend dependency versions are recorded in `uv.lock` and
  `frontend/pnpm-lock.yaml`. Their own licenses and notices remain applicable.
- No Python/Node dependency source tree or retrieval model weights are included
  in the public snapshot. Installation downloads third-party packages separately.
  The built frontend bundles React, React DOM and Scheduler; their original
  license texts are retained in `frontend/THIRD_PARTY_NOTICES.txt`.
- Official source URLs and acquisition metadata are under `docs/data/` and the
  source registry. Check the current source provider's terms before redistribution.
  Federal hosting does not establish that every attached manufacturer document or
  consumer narrative can be redistributed under this code license.
- Full complaints, VINs, private source caches, credentials, database files and
  actual human reply payloads are excluded from the public source snapshot.
- Synthetic fixtures are explicitly labeled; they are not substitute vehicle facts.

This project was developed with AI assistance. Automated implementation and tests,
actual human review, real API calls and simulated demonstrations are identified
separately in the reports. No independent human authorship or review is invented.
