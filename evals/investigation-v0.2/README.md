# 开发标签修订 v0.2

沿用 [v0.1的盲审与新增证据规则](../investigation-v0.1/README.md)。v0.1标签和旧评分均保留。

修订原因：结案和继续监测可以由不同原子结论覆盖；计数值、不能证明发生率、不能证明因果也是独立的判断。v0.1把它们写在同一参考结论里，会使完整性匹配依赖回答是否恰好合并句子。v0.2拆分这些参考结论，证据槽、来源定位、禁止推断和可接受处置均不变。

这次修订在阅读开发输出后进行，明确不是预注册的未见测试。由实现代理提出并应用于所有已保存开发轮次，不将修订结果声称为独立人工裁定。哈希及修订依据见 `revision.json`；脚本为 `scripts.revise_investigation_references`。原始v0.1分数和运行工件不覆盖，重评分另存 `scores-v0.2/`。

后续正式比较需冻结新参考版本，并按原计划建立独立事件隔离的未见测试集。`draft-review-fixtures.json` 是对精确保存报告的实现代理临时审查，不是对任意新答案的自动语义评分器。报告变化时脚本返回待审，不能复用旧判断。
