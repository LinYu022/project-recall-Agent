标签目前将`prius_symptom`、`prius_trigger`等作为义务名，不能据这些名称宣称已穷尽所有可验证断言。例如显式的制动距离表现仍需在完整题目/原文层面核查；评分不能只搜索“踏板感不一致”几个字就自动通过。`safety_boundary`和`relation_boundary`是语义边界义务，其单一定位只便于追溯，评价时必须结合其他来源段落、查询范围及两个机制。

正式审查前先核查标签是否覆盖题目；如需拆出更多原子义务、条件或等价证据，应建立新标签版本，并明确变更时间。这个开发首批可以用于修订后续设计，但旧报告/预检与旧标签仍保留；下一版测试必须在目标与标签先固定后执行。

没有给本表填“人类通过”，没有根据前两份历史人工判断外推新输出。审查有效工作时长当前未计时；后续按实际计时或自报保存，未测量继续null。
