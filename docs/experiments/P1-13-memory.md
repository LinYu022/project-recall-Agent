## 计划解释与限制

原计划不删功能。本模块以明确、有界声明提取实现异步候选路径，未接入LLM自动抽取自然语言。将来如替换提取器，仍必须遵守候选隔离、审核与P1-11外部请求恢复协议；本轮不将任意文字理解能力算成已完成。

操作规则仅限两项已安装并通过可执行检查的规则；任意新规则必须先实现验证，不接受模型自证。官方事实不写成独立真值，来源指针也不保证资料永远可用；原发布被回收或字节校验失败时拒绝采用。禁用/删除按活动采用失效，审计历史保留；不是对所有备份做物理擦除。

当前项目空间只属于一个认证owner，不提供团队共享ACL。相关度为词项排序，没有记忆召回率、回答质量或费用改善结论。情景历史检索、程序性Skill、综合实验、交互产品及GitHub发布按P1-14～P1-18继续。本轮停在P1-13等理解确认。
