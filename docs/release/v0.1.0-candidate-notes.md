# v0.1.0-candidate — 本地发行候选

本地可审查候选，尚未创建远端tag或GitHub Release。

支持固定发布的召回证据查询、原文重放、具体版本授权、持久化执行和恢复、三类可撤销记忆，以及React交互调查台。默认模拟模式使用合成资料，不调用外部模型。

公开副本保留代码、锁文件、MIT许可、第三方归属、数据获取说明、实验结果和演示材料。私人审查原文、访问凭据、数据/模型缓存和开发Git历史不分发；逐文件转换由公开清单标明。源引用与第三方运行时不适用本项目MIT再许可。

实际验证：独立公开源码目录557项离线检查及两组各7项HTTP通过，但复用既有Python依赖。四次容器构建尝试因镜像或依赖下载失败而没有完成应用验证。尚未执行远端克隆、远端CI及独立第二位使用者验收。

已知限制：模型确认验收不通过；部分细粒度评分与旧消融语义测量缺失。开发发布检查只是有限护栏，不证明任意回答有语义支持，不确认个车适用、因果或永久安全，也未证明Agent优于固定流程。

此候选没有新增外部模型请求或官方召回来源请求。正式公开仓库、tag、Release与附件须在实际上传和核验后另行登记，不能以本文件代替完成记录。
