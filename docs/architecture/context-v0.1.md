# P1-10：可核验的上下文构建

前置是 P1-09 同步调查闭环。`FrozenContext`仍负责固定资料、车型和时间选择；新增`prompt_context`只负责模型可见的表示与信息选择。摘要、分页结果和模型文本都不产生授权。

## 数据路径

工具完整结果 → 不可变工件及 EvidenceCard → 原始字节/解析/范围验证 → 结构化摘要 → 本轮上下文 → 模型决策 → 同一 Claim 校验。上下文构建器不会改写固定流程的来源、统计结果或验证规则。

`ContextBinding`绑定任务、release_id、任务契约哈希、计划哈希、控制修订、授权 ID 和执行代次；不包含执行秘密或用户令牌。提示中的`authorization_limits`明确车型/年份、时间和允许来源，实际执行仍由 P1-08 检查。

## 摘要与选择

默认采用确定性的抽取式摘要，没有新增摘要模型调用。`StructuredSummary`保留完整证据块、来源版本、定位、依赖、原始别名、反证别名、最近已知假设和未核实条件；Schema 见[公开契约](../../evals/context-summary-v0.1.schema.json)。它不是生成式语义概括，也不把假设状态当成事实。

重复合并要求文字、精确引用、来源版本、来源及范围通道相同；相似文字或不同版本不合并。所有等价 E 别名保留，最终反证检查允许同组的精确等价别名，原轨迹不改写。

必须保留的内容包括用户目标/计划、车型/年份和时间、允许来源、结构化计数/关系/全集结果、已经记录的反证，以及包含条件、否定、不确定或年款词项的完整文字块。它们的父段/范围依赖传递闭包一起保留。词项规则覆盖当前英文官方资料及常见中文标记，属于保守启发式，不是任意语言的语义完整性证明。未被识别的块仍可能因预算被省略，因此有显式省略清单和回查入口。

其余块按问题词项重合及最近获得顺序选择，每次加入完整依赖闭包并复算字符预算。去重不裁断句子、不删除选中块的否定词；必要集合超额就保存快照后停止。每轮只保留最近两条观察和最近一次完整决策，较早的假设状态、反证、所有尚未被核实关闭的证据缺口另行汇总。未再提及旧缺口不等于已解决。

预算同时服从每次输入及累计输入上限，字符数与`RunBudget`同口径；不冒充精确 token 数。报告记录前后字符数、构建耗时、摘要方式、调用数、未知/不适用的 provider usage 与费用。摘要调用数为 0；本地 CPU/磁盘耗时单独记录。

## 工件、分页与原文

完整快照、完整日志、全部候选、证据索引和摘要均保存为内容寻址 JSON，模型只接收服务器登记的 A001 等句柄，不能输入路径或哈希。D 是检索候选、E 是证据、A 是上下文工件，三者不能混用。

新增`read`决策只允许一个已登记工件句柄或当前证据别名，offset 为字符偏移，page_size 为 1～4000。返回 total_characters、next_offset、partial 和片段用途标志。页片段是导航，不独立变成新的证据卡。只完整展示过的块或完整读完的证据才可用于最终声明，父段依赖仍须展示；不能通过猜测隐藏别名绕过。读取和重试消耗原工具额度，读页重复仍受调用及重复上限限制。

已发布报告的`GET /tasks/{task_id}/context`支持 observations、planner_revisions、tool_calls、context_builds、artifact、evidence。它复用所有者、当前授权有效性及父任务边界检查；服务通过目录内的登记工件读取，没有任意文件接口。evidence 回查核对工具原始输出并重放固定发布的原始字节、解析版本及引用位置，返回原文页、来源版本和必要上下文别名。事务锁串行化撤销与本次披露；正在传输的已返回数据无法收回。

## 摘要恢复与缓存

恢复需要可信运行记录中的预期输入快照哈希和当前 ContextBinding，不能从不可信摘要自身推导二者。先校验工件字节哈希与绑定，再从输入快照重建摘要并比较内容；更换来源版本、删除否定词、丢失快照或更换修订/授权/epoch 都失败。Agent 在构建前还会重放全部原始证据；原文回查另做来源重放，不能仅凭摘要哈希宣称来源有效。

这实现的是上下文数据恢复与过期检测，尚不是后台 worker 重启或任务断点续跑；后者完整保留在 P1-11。缓存没有参与信息选择。本模块不依赖 provider 提示缓存，即使命中缓存也必须先通过相同字符、授权和引用检查。

## 兼容与实验

新服务及直接创建的 SingleAgent 默认使用 structured，固定调查仍是默认方法。显式 FixedConfig 缺少 context_mode 时取 full_history，保留旧配置语义；P1-09 精确响应回放沿用旧系统提示。命令行可通过`--context-mode full_history`选择旧行为。recent_window仅供消融，不作为正式服务默认。

合成练习比较完整历史、最近窗口和结构化摘要；真实资料检查只重建 P1-09 Prius 的未发送下一轮输入并回查来源，没有生成新回答。实验分类和全部限制见[P1-10记录](../experiments/P1-10-context.md)。P1-09 原始失败及用量不覆盖，不由输入缩小推导 Agent 质量提升。
