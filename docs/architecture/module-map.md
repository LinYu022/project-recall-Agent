## 为什么从任务开始

任务契约规定范围和可接受结论 → 数据模块决定要保存哪些字段 → 检索模块决定寻找哪些证据 → 调查模块据此判断是否完成 → 评测模块检验结论及成本。

如果先让模型自由回答，再凭回答倒推评分，容易把语气流畅误当作证据充分。P1-00 为后续所有方法提供共同的业务验收依据。

## 检查点与完整目标

- G1：00～06，数据与检索。
- G2：07～10，可信调查闭环。
- G3：11～12，协作与可靠执行。
- G4：13～15，三类记忆。
- G5：16～18，完整交付。

所有检查点都保留。无实测收益时记录负结果和默认策略，仍完成机制实现与验证。
