# P1-17 演示与独立使用者验收脚本

按 [产品说明](../../product-guide.md) 安装、构建、启动。录屏均是实际浏览器自动操作，不是用户访谈；正式来源模式的回答生成也仍是模拟。

## 演示顺序

1. 查看“模型质量验收未获证实”及当前运行模式。
2. 先输入无效访问凭据，确认业务查询被拒绝；然后用本机生成的访问令牌连接。
3. 缺少年份 → 等待输入 → 补充 2010 → 查询冻结资料。
4. 暂停 → 恢复计划 → 提出执行版本 → 检查范围与来源 → 批准具体版本 → 执行。
5. 同时观察“运行完成”“证据不足”“语义待审”，从一张文本卡定位原文及字段/页码，并读取执行回放。
6. 撤销授权，确认报告和原文不再可读。
7. 用 2011 年款查询 10V039000，解释有限来源零匹配边界。
8. 取消另一份计划，确认不能原地恢复；复制成新计划。
9. 用旧页面版本提交操作，确认冲突有明确解释。
10. 提交历史时点问题，确认接受冻结时间没有被默认勾选。
11. 比较 F-150 两条记录，固定关系，检查关系类型及未知条件。
12. 准备演示偏好候选、检查、确认、追到来源，再停用。
13. 显式模拟生成失败，确认没有成功样式的答案；检查实际失败事件。
14. 切换窄屏，确认文字与控件可读且无页面横向溢出。

自动入口：`pnpm --dir frontend test:e2e`。生成新目录，保留结果、请求状态、截图、视频和来源工件。不覆盖失败记录，不录制带认证头的浏览器 trace。

本轮录屏：[合成样例](synthetic-browser-demo.webm)、[正式 NHTSA 来源配模拟生成](official-sources-browser-demo.webm)。两套最终各19项通过；显式传输故障实际为 `PAUSED / unknown_model_output`，不能误称已经确认的失败结果。每份录屏旁的 media manifest 给出哈希。
