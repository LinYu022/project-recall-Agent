# Security

Do not put credentials, VINs, private complaints or access tokens in public issues.
Use GitHub private vulnerability reporting if the repository owner enables it;
otherwise contact the owner through an existing private channel before disclosing details.
No monitored security email address or response-time commitment is claimed.

The product is a local research prototype. Keep its port bound to localhost.
Use a dedicated database and random local access tokens. The API checks task ownership,
versioned approvals and provenance; a citation hash does not prove semantic correctness.
Model quality acceptance has not passed. Do not use this project to certify a vehicle's safety.
